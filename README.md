# خونه مادربزرگه 🐈💗 — نسخه‌ی رفع مشکل دکمه‌ها

## شروع سریع (پیشنهاد من)
فایل `index.html` به‌صورت مستقل آماده شده و CSS و JavaScript داخل خودش دارد؛ بنابراین برای اجرای دکمه‌ها لازم نیست فایل‌های جداگانه را آپلود کنی.

## انتشار روی GitHub Pages
1. یک Repository عمومی بساز.
2. فایل `index.html` همین پوشه را مستقیماً در ریشه‌ی Repository آپلود کن (نه داخل یک پوشه‌ی دیگر).
3. برو به **Settings → Pages**.
4. گزینه‌ی **Deploy from a branch**، شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب کن و Save بزن.
5. پس از انتشار، لینک ساخته‌شده را باز کن. اگر قبلاً نسخه‌ی قدیمی را منتشر کرده‌ای، فایل `index.html` را با نسخه‌ی جدید جایگزین کن و صفحه را با بارگذاری مجدد کامل باز کن.

این نسخه هیچ کتابخانه‌ی JavaScript خارجی لازم ندارد. فونت ممکن است در صورت نبود اینترنت به فونت جایگزین تبدیل شود، اما دکمه‌ها و بازی همچنان باید کار کنند.
